# Acceptance Testing is the FUTURE of Programming

Pairing acceptance testing and AI is a natural step in the advancement of software engineering. It is not so much a revolutionary step but perhaps an evolutionary step.

The goal of acceptance testing is to provide a "harness" or a "set of fixed points" for an AI implementation. These "fixed points" can then limit the variability of the AI implementation and lessen the likelihood failing to meet the software requirements.

Interestingly, this effort did not appear to use unit tests. Unit testing was not the focus of the video, but I found this difference from Bob Martin's ideas interesting.

AI can change the focus of software development from implementing a (vague) specification using code to writing (executable) acceptance tests. 

In summary, Dave Farley reports that this effort was almost correct. The differences required engineering review (and hand-holding). It is not really an unsupervised effort, but requires (close?) supervision.

In conclusion, from Dave Farley himself, pairing acceptance testing and AI implementation is "A viable strategy to raise the level of abstraction in programming."
