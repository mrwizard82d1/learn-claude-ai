# My LLM codegen workflow atm

Read https://harper.blog/2025/02/16/my-llm-codegen-workflow-atm

Unfortunately, I found this article to be similar (and repetitive) of other articles: "I tried using AI to generate a project and it was great". I found it encouraging that he did talk about brownfield development, but the discussion was very brief.

It could be great, but I'm skeptical. The article mentioned little about maintaining AI code long term and discussed nothing about software engineering: optimizing all the "-ilities" of a code base to achieve a business goal at an acceptable cost. 

It is possible that AI-assisted development lowers the cost of both initial development and maintenance so much that software engineering no longer matters, but I'm not yet convinced.
