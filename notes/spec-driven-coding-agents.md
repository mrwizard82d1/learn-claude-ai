# Spec-Driven Development using Coding Agents

In general, this video described a process different from what I expected, but not really incompatible with my ideas. I like the idea of a project "constitution" which differs from "feature development". My idea of the "red acceptance - red/green/refactor - green acceptance" applies much better to "feature development", but I think I have also have a better understanding of the "project constitution":

- Mission
- Tech stack
- Roadmap

Additionally, I was (very) impressed by Paul's video on how to apply this same process to a "brownfield" process. Although too short for my current work, even seeing a small (and very fast) example of using this process for "brownfield" development was useful (and inviting).

I do wish he had shown more about using test-driven development or behavior-driven development. Unfortunately, the tests seemed to be almost an "after-thought". Not quite because of other recommendations I've seen from both Paul and JetBrains, but the emphasis was applying AI assistance to the whole process and not on actually designing an effective process.
